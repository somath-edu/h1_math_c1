# 개념 2: 연산의 법칙

다항식의 덧셈과 뺄셈에서 연산 법칙(교환·결합법칙)을 활용해 계산 실수를 줄이고 정답을 도출하는 실전 유형입니다.

## 🔥 실전 출제 유형

실제 시험에서는 괄호와 마이너스(-) 부호가 복잡하게 얽혀 있는 식을 제시하여 연산 실수를 유도하는 문제로 자주 출제됩니다.

* **유형 1: 복잡한 괄호 풀기** ─ 소괄호, 중괄호, 대괄호의 순서에 따라 분배법칙을 적용하여 식 전개하기
* **유형 2: 빼는 식의 부호 주의하기** ─ 마이너스(-) 부호를 분배할 때 모든 항의 부호를 정확히 바꾸기

## 🎯 단 하나의 대표 문제

두 다항식 $A = 2x^2 + 3x - 1$, $B = x^2 - x + 4$ 에 대하여 $2A - (A + 2B)$ 를 간단히 정리하시오.

### 💡 문제 해결의 열쇠 (풀이 과정)

**[1단계]** 연산 법칙으로 식 간단히 하기

괄호를 먼저 풀고 동류항끼리 정리합니다.

$2A - (A + 2B) = 2A - A - 2B = A - 2B$

**[2단계]** 다항식 대입하기

정리된 식에 $A$와 $B$를 대입합니다.

$A - 2B = (2x^2 + 3x - 1) - 2(x^2 - x + 4)$

**[3단계]** 분배법칙 및 동류항 정리

$= 2x^2 + 3x - 1 - 2x^2 + 2x - 8$

$= (2-2)x^2 + (3+2)x + (-1-8)$

$= 5x - 9$
