# 개념 1: 나눗셈의 관계식과 조립제법

## 핵심 정의
다항식 𝐴를 𝐵로 나누었을 때 몫이 𝑄, 나머지가 𝑅이라면, 𝐴 = 𝐵 · 𝑄 + 𝑅 로 나타냅니다.

## 단 하나의 핵심 예시
* 식: (𝑥² + 3𝑥 + 2) ÷ (𝑥 + 1)
* 관계식: 𝑥² + 3𝑥 + 2 = (𝑥 + 1)(𝑥 + 2) + 0
* 도구: 1차식으로 나눌 때는 '조립제법'을 사용하여 계수만으로 몫과 나머지를 빠르게 구함.

## 원리
나눗셈의 본질은 단순히 나누는 행위가 아니라, 식을 나누는 식을 포함한 구조로 재조립하는 과정입니다. 조립제법은 1차식 나눗셈의 계수 연산을 체계화한 강력한 도구입니다.
