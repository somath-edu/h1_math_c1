# 다항식의 나눗셈

다항식의 나눗셈은 식의 구조를 파악하는 가장 강력한 도구입니다. 이 단원에서는 복잡한 계산을 단숨에 해결하는 **조립제법**을 먼저 마스터한 뒤, 나눗셈의 원리와 구조를 깊이 있게 탐구합니다.

:::info
### 📖 학습 목표
<ul>
  <li>다항식의 나눗셈에서 <strong>나눗셈 관계식</strong> $A = BQ + R$을 이해하고 적용할 수 있다.</li>
  <li>나눗셈 전 <strong>내림차순 정리</strong>와 빠진 차수를 계수 $0$으로 채우는 법을 익힌다.</li>
  <li><strong>조립제법</strong>을 이용하여 1차식으로 나누는 계산을 빠르고 정확하게 수행할 수 있다.</li>
</ul>
:::
